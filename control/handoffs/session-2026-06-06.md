### 3. Placebos in-space — spec non-OECD base (83 donantes)

```
Pseudo p-value (Fisher exact): 0.75
```

**Discrepancia con McCloud (0.08–0.09) identificada y documentada.** Causa probable: pysyncon calcula el MSPE-ratio sobre todo el período post-2001 hasta 2023 (22 años); McCloud usa datos hasta ~2016 (15 años). El gap de México se reduce hacia cero en años recientes, diluyendo el ratio. Truncar artificialmente a 2016 sería p-hacking sin justificación teórica. Se reporta como discrepancia metodológica conocida.

### 4. Robustness: spec non-OECD + gross_savings (56 donantes)

| Métrica | Base (83 donors) | + savings (56 donors) | McCloud |
|---|---|---|---|
| RMSPE | **0.1074** | 0.2707 | 0.12 |
| Gap 2008 | **−6.50 pp** | −4.75 pp | −7.48 pp |
| p-value | 0.75 | 0.47 | 0.08–0.09 |

**Conclusión: agregar savings empeora el fit**. La spec non-OECD sin savings es la canónica. Donantes perdidos al agregar savings: Mauritania (9.7%), Chad (3.6%), Guinea-Bissau (1.7%), Kuwait (0.5%).

Nuevos archivos en `out/`: `mexico_*_savings.png` (3 imágenes).
