### 4. Incidente: nbconvert corrompió el CSV

Al ejecutar `nbconvert --execute --inplace`, la API del Banco Mundial falló silenciosamente (posible rate-limiting en modo headless), resultando en datos corruptos: ~30 países completos en vez de 122, México con 11/11 missing en outcome. El CSV se sobrescribió con solo 27 países.

**Solución:** Se restauró el CSV desde git (`git show 8719709:data/panel_mccloud_mexico.csv`) y se re-filtró a la muestra non-OECD (108 países) con un script standalone.

**Lección:** No usar `nbconvert --execute` para este notebook; las descargas de API deben correr interactivamente en VS Code/Jupyter.
